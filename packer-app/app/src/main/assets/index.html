Lua → APK через GitHub

Загрузи файлы, нажми кнопку, страница сама отправит всё в твой репозиторий, запустит сборку и покажет ссылку на APK.

1. Доступ к GitHub

Как получить токен (один раз)
  1. Открой github.com → фото профиля → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories, выбери свой репозиторий.
  3. Permissions → Repository permissions: Contents: Read and write, Actions: Read-only. Если файла автосборки в репозитории ещё нет, добавь ещё Workflows: Read and write.
  4. Создай токен и скопируй его сюда. Токен показывается один раз.

Токен хранится только в твоём браузере и отправляется только на api.github.com. Никому его не показывай.

В этом режиме название, код и иконка ниже не используются. Выбери ZIP с проектом или отдельные файлы в блоке «Файлы», введи нужный репозиторий и нажми кнопку. Токену нужно право Workflows: Read and write.

Файлы можно кидать как попало: .java/.kt, разметку .xml, картинки, звуки. Я разложу их по папкам проекта Android, добавлю недостающие файлы сборки (манифест, Gradle, автосборку) и отправлю на GitHub. Если в файлах уже есть settings.gradle, это готовый проект, и всё кладётся как есть. Кнопка «Показать раскладку» только показывает, что будет сделано, ничего не отправляя.

3. Код (main.lua)

Если ты загрузишь свой main.lua (файлом или в ZIP), он будет главнее этого поля. Очисти поле, если main.lua в репозитории менять не нужно.

4. Файлы (необязательно)

    Количество файлов не ограничено: нажимай кнопку выбора сколько нужно раз, файлы добавляются в список. Можно выбрать ZIP-архив с папкой проекта, он распакуется сам. Файлы .lua в корне остаются в корне (подключаются через require), всё остальное, включая вложенные папки, попадает в assets.

    Добавить файл текстом (без выбора файла)

    Так можно добавить любое количество модулей: впиши имя, вставь код, нажми «Добавить», повтори для следующего.
